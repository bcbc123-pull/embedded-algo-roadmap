---

## 参考答案

1. `char` = 1、`short` = 2、`int` = 4、`long` = 4（Windows）/ 8（Linux）、`long long` = 8。
   ⚠️ `long` 的大小是**平台相关**的，这是「实现相关行为」的典型例子。
2. `float` = 4、`double` = 8（绝大多数平台）。
3. `signed int`：-2³¹ ~ 2³¹-1（约 -21 亿 ~ 21 亿）；`unsigned int`：0 ~ 2³²-1（约 0 ~ 42.9 亿）。
4. ⚠️ 平台相关。x86 + gcc 默认 `char` = **signed char**。验证方法：

   ```c
   #include <stdio.h>
   int main(void) {
       char c = 0xff;
       printf("%d\n", (int)c);   // 有符号 → -1；无符号 → 255
       return 0;
   }
   ```
5. **清除 x 最低位的 1**（把二进制最低的那个 1 变 0）。判断 2 的幂：`x > 0 && (x & (x - 1)) == 0`。
6. `1 << 5` = 32。⚠️ `1 << 31` 是**未定义行为**：`1` 是 `signed int`，左移溢出到符号位，标准不保证结果（多数平台得到 `0x80000000` = -2147483648，但不要依赖）。
7. `~0` 对 `int` = **-1**（补码全 1）；对 `unsigned int` = `0xFFFFFFFF` = 4294967295。
8. `5 / 2` = **2**（整数除法截断）、`5 % 2` = **1**。得到 2.5：`5.0 / 2` 或 `(float)5 / 2`。
9. `i++` 返回旧值再自增；`++i` 先自增再返回新值。单独一句用时两者效果相同。⚠️ `i = i++` 是**未定义行为**（同一表达式内多次修改 `i` 且无序列点），结果不保证，别写。
10. 会「贯穿」(fall through) 继续执行下一个 `case` 的代码，直到遇到 `break` 或 `switch` 结束。可被有意利用，但通常要补 `break`。
